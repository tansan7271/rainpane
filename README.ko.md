# Rainpane

[English](README.md)

Mac 화면에 비를 내리는 메뉴바 앱입니다. 창 윗변에 물이 고이고, 옆면을 타고 흘러내리고, 모서리에서 떨어집니다.

## Weatherling에서 시작했습니다

Rainpane은 Matt Senter의 [Weatherling](https://apps.apple.com/app/weatherling/id6813641198)에서 아이디어를 얻었습니다. 마음에 들어서 Claude Code로 제 입맛대로 어디까지 다시 만들 수 있나 해 보고 싶었습니다.

- 아이디어만 가져와 따로 만들었습니다. Weatherling의 코드나 에셋은 들어 있지 않고, 제휴 관계도 없습니다.
- 재미로, 또 공부하려고 만들었습니다. Weatherling과 경쟁하거나 권리를 침해하려는 뜻은 없습니다.
- Weatherling은 앱 샌드박스 안에서 동작하고 권한을 하나도 요청하지 않습니다. Rainpane은 macOS 비공개 API를 쓰고, 최적화도 제가 필요한 만큼만 했습니다. 잘 다듬은 앱을 원하시면 Weatherling을 사서 아이디어를 낸 개발자를 응원해 주세요.
- Weatherling 개발자께서 바꾸거나 내리길 바라시는 부분이 있으면 이슈로 알려 주세요. 바로 고치거나 내리겠습니다.

## 기능

- 비는 창 뒤로 내립니다. 맨 앞 창은 젖지 않고, 뒤에 있는 창일수록 비를 더 맞습니다.
- 창 윗변에 물이 고이고, 모서리를 돌아 옆면으로 흘러내리고, 아래 모서리에서 떨어집니다.
- 창을 닫거나 최소화하거나 가리면, 고여 있던 물이 화면을 타고 수막처럼 흘러내립니다.
- 창 유리를 타고 물방울이 굴러 내려옵니다. 바탕화면 위젯에도 물이 고입니다.
- 클릭하면 물방울이 생깁니다. 버튼을 누르고 있으면 퍼지고, 누를 때와 뗄 때 잔 물방울이 튑니다. macOS 26 이상에서는 리퀴드 글래스로 그립니다.
- 선택: 키보드 물방울. Enter나 Tab을 누르면 물방울이 튑니다.
- 선택: 모든 모니터의 데스크톱을 함께 넘깁니다. 한 모니터가 N번째 데스크톱으로 넘어가면 다른 모니터도 따라갑니다.
- 영어와 한국어를 지원합니다.

## 요구 사항

- macOS 15 이상. macOS 27을 쓰는 Apple Silicon Mac에서만 확인했습니다.
- Xcode 또는 Command Line Tools (Swift 6).

## 빌드와 실행

```sh
git clone https://github.com/tansan7271/rainpane.git
cd rainpane
./setup-signing.sh   # 선택, 처음 한 번. 다시 빌드해도 권한이 유지되게 로컬 자체 서명 인증서를 만듭니다.
./build.sh run
```

앱은 메뉴바에 있습니다. 왼쪽 클릭하면 설정이 열리고, 오른쪽 클릭하면 비를 켜거나 끕니다.

## 권한과 개인정보

기본 설정에서는 권한을 하나도 요청하지 않습니다.

- 화면에 있는 창의 위치와 크기를 읽습니다(`CGWindowListCopyWindowInfo`). 창 제목은 읽지 않고, 화면 기록 권한도 필요 없습니다.
- 물방울 위치를 정하려고 마우스 클릭을 감지합니다. 권한은 필요 없습니다.
- 키보드 물방울과 데스크톱 함께 넘기기는 기본으로 꺼져 있습니다. 둘 중 하나라도 켜면 손쉬운 사용 권한을 요청합니다.
  - 키보드 물방울은 Enter와 Tab에만 반응합니다. 포커스가 있는 칸의 종류, 위치, 크기, 텍스트 커서 위치만 읽습니다. 입력한 내용은 읽지 않고, 비밀번호 칸은 건너뜁니다.
  - 데스크톱 함께 넘기기는 모니터마다 몇 번째 데스크톱인지 읽고, 다른 모니터도 넘어가도록 macOS "데스크톱 N(으)로 전환" 단축키를 대신 누릅니다. 그 단축키가 꺼져 있으면 설정에 있는 버튼으로 켤 수 있습니다. 키보드 설정은 이 버튼을 누를 때만 바꿉니다.
- 네트워크에 연결하지 않습니다. 설정은 앱 자체 환경설정에 저장합니다.

## 비공개 API

macOS가 업데이트되면 동작하지 않을 수 있습니다.

- SkyLight `SLSCopyManagedDisplaySpaces`: 모니터별 데스크톱을 읽습니다(데스크톱 함께 넘기기).
- 비공개 Core Animation 레이어의 리퀴드 글래스 필터 값: 유리 물방울을 완전히 맑게 합니다.
- `com.apple.symbolichotkeys`와 `activateSettings -u`: 데스크톱 단축키를 켜는 버튼을 누를 때만 씁니다.

## 만든 방식

처음부터 끝까지 바이브 코딩으로 만든 프로젝트입니다. 원하는 것은 주로 스크린샷과 느낌을 적은 메모로 설명했고, 코드는 Claude Code가 전부 썼습니다. 작업을 한국어로 했기 때문에 코드 주석과 설계 메모([ARCHITECTURE.md](ARCHITECTURE.md))도 한국어입니다. 설계 메모는 영어 번역본([ARCHITECTURE.en.md](ARCHITECTURE.en.md))도 있습니다. 원본은 한국어판입니다.

한계:

- 코드는 제가 쓰지 않았고, 한 줄씩 전부 검토하지도 않았습니다. 다듬어지지 않은 곳이 있을 겁니다.
- 최적화는 "내 Mac에서 충분하다"에서 멈췄습니다. 화면 전체 크기의 투명 창을 초당 60번 다시 그리는 데는 늘 시스템 비용이 듭니다. 4K 모니터 두 대를 연결한 제 M1 Pro에서는 비가 내리는 동안 CPU를 약 17% 씁니다. 설정 → 성능에서 줄일 수 있습니다.
- 하지 않은 최적화: 그리기와 창 목록 읽기가 메인 스레드에서 돌아갑니다. 렌더 스레드를 따로 두면 창이 한꺼번에 많이 움직일 때 나아질 겁니다.
- 제 환경에서만 확인했습니다.
- 최소화 애니메이션이나 미션 컨트롤처럼 macOS 내부 동작을 짐작해서 처리한 부분이 있어서, 가끔 잘못 판단할 수 있습니다.
